# Audit Log Template

**Document Version:** 1.0  
**MoProtect Protocol Version:** 1.0  
**Last Updated:** 2026-01-01  

## Overview

This template specifies the structure and required fields for audit logs generated by the Jubilant Train pipeline. Audit logs serve as immutable records of all sanitization, validation, and sealing operations—critical for legal defensibility and regulatory compliance.

---

## Field Definitions

| Field | Type | Description | Required |
|-------|------|-------------|----------|
| `timestamp` | ISO 8601 | UTC timestamp of operation | Yes |
| `status` | String | Operation result (success, failed, warning, completed) | Yes |
| `findings` | Array | Array of detected issues/violations | No |
| `findings_count` | Integer | Total number of findings | Yes |
| `file_hash_input` | SHA-256 | Hash of input file before processing | Yes |
| `file_hash_output` | SHA-256 | Hash of output file after processing | Yes |
| `compliance_status` | String | Overall compliance assessment | Yes |
| `moprotect_steps` | Array | Which MoProtect protocol steps were executed | Yes |
| `operator` | String | Who/what ran the operation (e.g., "automated", "user_email") | Yes |

## Retention Policy

- **Retention Period:** 7+ years (recommended)
- **Storage Location:** Tamper-proof storage (consider blockchain for critical IP)
- **Access Control:** Restricted to authorized personnel only
- **Archival Format:** JSON (human-readable, machine-parseable)

---

## Compliance Verification

To verify audit log integrity:

1. **Hash Verification:**
   ```bash
   echo "Original JSON content" | sha256sum
   # Compare output with audit_log_hash field
   ```

2. **Timestamp Verification:**
   - Verify all timestamps are in ISO 8601 format
   - Confirm all operations completed in logical sequence

3. **Seal Verification:**
   - Hash the artifact file
   - Compare with content_hash in seal record
   - If they match, artifact has not been tampered with

## Example Usage in Code

```python
from jubilant_train.sanitizer import CodeSanitizer
from jubilant_train.validator import ComplianceValidator

# Sanitize with audit log
sanitizer = CodeSanitizer()
report = sanitizer.sanitize_directory("./src", "./sanitized")
sanitizer.generate_audit_log("./audit_logs/sanitization.json")

# Validate with audit log
validator = ComplianceValidator()
validator.validate_directory("./sanitized")
validator.generate_compliance_report("./audit_logs/validation.json")
```
